# DEKIRU Game Creator

先生や保護者が、お子さんに合わせた学習ゲームを作るためのブラウザーアプリです。
現在は Typing「和室・襖」に対応しています。その他のゲーム形式・テンプレートは準備中です。

## 使い方

1. トップページで Typing「和室・襖」を選びます。
2. セット名を入力し、Excelなどから「問題・正解・よみ」の3列をコピーして貼り付けます。
3. 「問題を読み込む」を押し、問題一覧を確認・編集します。
4. 「プレビューを再スタート」で最新の問題を試します。
5. 「HTMLを書き出す」で、画像・音声を含む1つのHTMLをダウンロードします。

問題はブラウザー内で処理します。入力した問題や選んだ編集用ファイルをアプリからサーバーへ送信する処理はありません。

## 保存・再編集

- **問題セットを保存**：先生・保護者が後から編集するための `.dekiru.json` ファイルをダウンロードします。未入力のある下書きでも保存できます。
- **問題セットを開く**：保存した `.dekiru.json` を読み込みます。内容を置き換える前に確認が出ます。
- **HTMLを書き出す**：子どもが遊ぶためのファイルです。このHTMLを編集用ファイルとして読み込むことはできません。

自動保存ではありません。閉じる前に編集用ファイルを保存し、ダウンロード先を確認してください。
貼り付け欄の内容は「問題を読み込む」で問題一覧に反映してから保存します。
ゲームの途中経過・得点は編集用ファイルに含まれません。

## 開発・動作確認

Node.js 22以降を使います。追加のパッケージインストールは不要です。

```sh
node tools/preview-server.mjs --port 4173
node --test tests/*.test.mjs
node tools/build-sample-export.mjs
```

ローカルでは `http://127.0.0.1:4173/` を開きます。
生成したサンプルは `dist/typing-fusuma-sample.html` です。生成物はGit管理に含めません。
ブラウザー確認用ページは `tests/` にあります。

## 構成

- `index.html`：公開URLからトップページへ移動する入口
- `app/`：Game Creatorのトップページと共通色
- `core/`：問題読み込み、音声管理、HTML書き出しなど
- `Typing/creator/`：問題作成・保存・読み込み画面
- `Typing/core/`：タイピング判定と問題進行
- `Typing/templates/fusuma/`：襖の画像・音声・演出
- `tests/`：自動テストとブラウザー確認
- `tools/`：ローカル確認とサンプル生成

## GitHub Pages

この構成はGitHub Pagesのプロジェクトサイトに対応しています。
`main` ブランチのルート (`/`) を公開元に設定します。`.nojekyll` によりファイルをそのまま配信します。

実際に作成した教材、バックアップ、元の作業用ファイル、認証情報はリポジトリへ含めないでください。
画像・音声に新しい利用・再配布許諾を付与するものではありません。素材を別用途に利用する場合は、各素材の利用条件を確認してください。
