# 問題画像・問題別プレビュー受入れ記録

更新：2026-09-30。ローカル実装・受入れ試験まで。本番へは未反映。

## 実装した操作

- 各問題の「削除」の次に「プレビュー」。右側に問題を直接表示し、文章・画像・配置・説明の編集を即時反映する。
- JPEG/PNG/WebPを端末内で検査・縮小。上下左右を選択し、狭い画面では上下へ自動配置する。
- 編集用ファイルと単一HTMLに画像を同梱。クラウドは旧・新両形式を読取り、画像の書込みはサーバー側の準備完了まで無効。
- 画像の処理中・通信中の編集・ログイン退避容量不足で内容を失わない。問題プレビューは無音・入力なし、全体へ戻ると開始画面から。
